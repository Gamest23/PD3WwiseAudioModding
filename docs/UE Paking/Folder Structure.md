# Making Mod Folder Structure

While this is cooking, let’s make our mod folder structure! I personally made a folder on my Desktop called “Payday 3 Mods” and put them all in there. 

To make this process even simpler, you can download this [.zip file](https://www.dropbox.com/scl/fi/9gf598r7bh0asrwzk9zwv/Wwise-Mod-File-Format-rename-me.zip?rlkey=a8q03pyz57w0ckxfn6nuafr78&st=orf0yvm7&dl=1) to have the folder format automatically made for you. All you need to do is extract it, rename the folder that says so, and read the ```READ ME.txt``` for the next step.
