# Windows

## Blank Project or PDML?

There are 2 ways making mods at the moment.

- You can use blank Unreal Engine project and setup Wwise integration manually
    - Doing this will not require the install of the [Payday Modloader](https://modworkshop.net/mod/59255) <span class="dark">:Icons-mws_logo_white:</span><span class="light">:Icons-mws_logo_black:</span> for end-users
    - But will mark you as a modder for online games with the mod installed
    - Uses at a minimum `50 GB` of storage

- Or you can install the [Payday Modkit](https://payday3-modding.github.io/Documentation/payday3-modding/index.html) and follow different steps.
    - Doing this **will** require the install of the [Payday Modloader](https://modworkshop.net/mod/59255) <span class="dark">:Icons-mws_logo_white:</span><span class="light">:Icons-mws_logo_black:</span> for end-users
    - But will **not** mark you as a modder for online games (as of right now)
    - Uses at a minimum of `80 GB` of storage
    - Will also have the benefits of Payday Mod loader such as:
        -  In-Game Mod Manager
        -  Integrated Mod Settings
        -  And more

!!! note
    You could install apps/project files like the Unreal Engine, Wwise Project, and Unreal Projects somewhere other than the C: drive. Though errors you may encounter will require some low-level PC knowledge to be fixed.

!!! info
    Creating custom heist jukebox add-on mods, or next to any jukebox add-on mods, will require the install of the Modkit

If you wish to just use a blank Unreal Engine Project, then continue. If you wish to use the Modkit, then follow the [Payday 3 Modding Documentation](https://payday3-modding.github.io/Documentation/payday3-modding/index.html)

!!! warning
    Linux users may struggle with some of the steps for the Modkit


This process also **requires** admin privilege access on your windows device
