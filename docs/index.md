## Benefits?

“What are the benefits of replacing audio with Events instead of just using [PD3AudioModder](https://modworkshop.net/mod/51045) <span class="dark">:Icons-mws_logo_white:</span><span class="light">:Icons-mws_logo_black:</span>?”

To start, PD3AudioModder no longer works 100%. You can still theoritically still use the tool, though it's "convenience" factor is lost.

You can see later on what "exactly" PD3AudioModder was doing/replacing, and how limiting it was.

With Event replacing, the audio can be as long as you want, be fancy with transitions, custom list of audio to play in a sequencial list, control of which audio to play randomly, and more! 

It will also have the advantage of making audio mods smaller in size with compression methods built into Wwise.

## Tools to install

??? Repak
    Even though modding no longer uses just .pak files, it's still requried to have one .pak file to contain the Wwise media (your audio files) for your events to play. [Repak in File Explorer Menu](https://modworkshop.net/mod/50337) <span class="dark">:Icons-mws_logo_white:</span><span class="light">:Icons-mws_logo_black:</span> makes it slightly easier to make them.

??? "File Converter" 
    Use [File Converter :fontawesome-brands-windows:](https://file-converter.io/?from=readme.md) to easily and locally convert files, instead of relying on online tools and their restrictions.

??? "File Converter (Linux)" 
    If you use Linux, you can use [Linux-File-Converter-Addon :simple-linux:](https://github.com/Lich-Corals/linux-file-converter-addon) to convert local files just as easy.
